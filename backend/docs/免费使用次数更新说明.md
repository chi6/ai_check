# 免费使用次数更新说明

## 更新内容

本次更新将系统中的免费使用次数从**100次**更改为**10次**，具体包括以下更改：

1. 修改数据库模型中新用户的默认免费使用次数为10次
2. 更新现有用户的免费使用次数限制为10次
3. 更新系统提示和说明文本

## 实现方式

我们创建了以下几个脚本来完成这次更新：

1. `backend/scripts/update_db_for_usage.py` - 修改了数据库模型中新用户的默认免费使用次数
2. `backend/scripts/update_existing_users_limit.py` - 更新现有用户的免费使用次数限制
3. `backend/update_free_usage_to_10.py` - 一键执行以上两个脚本的主脚本

同时，我们还更新了以下文件中的文本描述：

- `backend/setup_usage_features.py` - 将描述中的"每个新用户有100次免费使用机会"修改为"每个新用户有10次免费使用机会"

## 执行方法

要执行此次更新，您只需运行以下命令：

```bash
cd /path/to/your/project
python backend/update_free_usage_to_10.py
```

该脚本会自动执行以下操作：

1. 更新数据库中的默认免费使用次数为10次
2. 将所有现有用户的免费使用次数限制从100次更改为10次

## 验证方法

执行完更新脚本后，您可以通过以下方式验证更改是否生效：

1. 查看数据库中用户的免费使用次数限制：

```sql
SELECT id, username, free_usage_limit FROM users LIMIT 10;
```

2. 创建新用户并检查其免费使用次数限制是否为10

3. 通过前端界面登录，查看显示的免费使用次数是否正确

## 注意事项

1. 此更新会影响所有现有用户的免费使用次数限制
2. 如果有用户已经使用超过10次，但尚未达到原来的100次限制，他们将无法再使用免费额度
3. 建议在执行更新前备份数据库
4. 更新操作不可逆，请确保您确实需要进行此更改
